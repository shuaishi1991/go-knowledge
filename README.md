# 围棋书房

静态网站，用来查阅围棋术语、定式和布局。首页是书架，每本书单独成册。进入一本书之后，页面只链回书房，不链到其他书，方便以后增加或删掉一本书。

## 书籍

**术语。** 162 条中文术语，分成行棋手段、棋形与模样、死活对杀、规则胜负、段位赛事、历史头衔六类。带谱的条目可以一手一手翻看。

**定式。** 4163 条变化，每条单独一页，从第一手走到这条变化的最后一手。先按黑棋起手归类，再按白棋应手，最后按结果分成理想、好棋、骗着、恶手。

**布局。** 40 个大类，其下 585 个开局型。目录只列名称，点进一型才看棋盘。来源网站有些分类页打不开，这些分类会显示为 0 型。

## 棋盘

书里的每一页都是同一套结构：顶栏标明书房和当前这本书，左边是这一级的目录，右边是正文。目录只列同一级的条目，不把另外两本书混进来。屏幕够宽、也够高时，目录固定在左边；窄屏或矮屏时，顶栏留下目录按钮，点开从左边滑出。正文上方是路径。宽屏棋盘在左、说明在右，窄屏说明在棋盘下面。高度不够时，棋谱页只留目录按钮和棋盘，说明在自己的区域里滚动。翻谱按钮在棋盘下方：第一手、快退、上一手、下一手、快进、最后一手。坐标和手数收在右侧三个点里，默认关闭。没气的棋会被提掉。定式说明里的 A、B、C 会标在对应的点上。

## 查看

在项目根目录运行：

```bash
python3 -m http.server 8765
```

然后打开 <http://127.0.0.1:8765>。

## 重新生成页面

资料在 `data/`。改完数据或页面模板后，在项目根目录运行：

```bash
python3 tools/build_pages.py
```

增删一本书，改 `tools/build_pages.py` 里的 `BOOKS`。`id` 对应该书的目录和生成函数。

## 来源

术语取自 Go Magic 中文术语表，只保留中文。定式取自 OGS 定式字典。布局取自围棋学研网的布局分类、谱数和黑胜率。棋盘按 GoMagic 的木纹棋盘和落子操作。
