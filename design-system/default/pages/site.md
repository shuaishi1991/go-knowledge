# 围棋书房页面覆盖

这套规则盖过 `MASTER.md` 里不适合书房的部分。颜色、字体和动效仍以 Master 的「书籍阅读」系统为准。

## 不用的落地页结构

Master 给出的 Hero、用户评价轮播和行动按钮是营销页结构。书房是查阅站：首页是三本书，书内是目录和棋谱。不要加评价、注册或购买按钮。

## 用在页面上的决定

- 风格取书籍阅读系统的瑞士式克制，纸色取同一系统的暖纸 `#FFFBEB`，正文用墨色 `#1A1A1A`，点缀用赭石 `#92400E`。不用百科蓝紫，也不用美术馆纯黑白。
- 琥珀色按钮 `#D97706` 只像警告色，链接和当前项用 `#92400E`。
- 中文用 Noto Serif SC，西文标题用 Cormorant Garamond，正文用 Crimson Pro。
- 页面结构是阅读站，不是营销页。顶栏只放书房名和当前书名。宽而高的屏幕，左侧固定这一级目录，正文在右，路径留在正文上方。窄屏或矮屏，目录收进按钮滑出的侧栏。棋谱页在高度不够时只留目录按钮和棋盘。木纹棋盘本身不改。
- 动效只留 200ms 的边框和背景变化。系统要求减少动效时，取消这些过渡。
